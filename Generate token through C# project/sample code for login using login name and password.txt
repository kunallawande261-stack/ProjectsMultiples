using System;
using System.Net.Http;
using System.Threading.Tasks;
using IdentityModel;
using IdentityModel.Client;

class Program
{
    static async Task Main(string[] args)
    {
        await GetAccessToken();
    }

    static async Task GetAccessToken()
    {
        var client = new HttpClient();

        // Request authorization code
        var authorizeResponse = await client.RequestAuthorizationCodeTokenAsync(new AuthorizationCodeTokenRequest
        {
            Address = "http://localhost/InnovatorServer/oauthserver/connect/token",
            ClientId = "InnovatorClient",
            RedirectUri = "http://localhost/InnovatorServer/Client/OAuth/PopupCallback",
            Code = "authorization_code", // Replace with the authorization code obtained from the authorization server
            CodeVerifier = "code_verifier", // Replace with the PKCE code verifier
            ClientSecret = "client_secret", // Replace with the client secret
            GrantType = OidcConstants.GrantTypes.AuthorizationCode,
            CodeChallengeMethod = OidcConstants.CodeChallengeMethods.Sha256,
            Scope = "openid Innovator offline_access"
        });

        if (authorizeResponse.IsError)
        {
            Console.WriteLine(authorizeResponse.Error);
            return;
        }

        Console.WriteLine($"Access Token: {authorizeResponse.AccessToken}");
        Console.WriteLine($"Refresh Token: {authorizeResponse.RefreshToken}");
    }
}




ASP.NET Core, .NET Core, and .NET Framework are different components of the Microsoft .NET ecosystem, each serving different purposes and targeting different scenarios. Here's a brief explanation of each:

ASP.NET Core:

ASP.NET Core is a cross-platform, high-performance framework for building web applications and APIs using the C# programming language.
It's open-source and can run on Windows, macOS, and Linux.
ASP.NET Core provides a modular and lightweight architecture, allowing developers to build and deploy applications more efficiently.
It includes features such as built-in dependency injection, middleware pipeline, and support for modern web development practices like MVC (Model-View-Controller) and Razor Pages.
ASP.NET Core is designed for building cloud-native, scalable, and modern web applications.
.NET Core:

.NET Core is a cross-platform, open-source framework for building various types of applications, including web, desktop, and IoT (Internet of Things) applications.
It's a modular framework that includes a runtime, libraries, and development tools.
.NET Core is optimized for performance, scalability, and agility, making it suitable for building applications that need to run on different platforms and environments.
It provides support for modern development practices, such as microservices architecture, containerization, and cloud-native deployment.
.NET Core is often used in scenarios where cross-platform compatibility, performance, and flexibility are essential.
.NET Framework:

.NET Framework is a Windows-only framework for building Windows desktop applications, web applications, and services.
It's been around for many years and has a vast ecosystem of libraries, tools, and components.
.NET Framework includes ASP.NET, which is used for building web applications, as well as Windows Forms and WPF (Windows Presentation Foundation) for building desktop applications.
While .NET Framework has extensive support and compatibility with existing Windows applications, it's not as lightweight or cross-platform as .NET Core.
.NET Framework is suitable for building Windows-specific applications and services that don't need to run on other platforms.
In summary, ASP.NET Core is a framework for building web applications, .NET Core is a cross-platform framework for building various types of applications, and .NET Framework is a Windows-only framework for building Windows-specific applications. Each serves different purposes and targets different scenarios, so the choice depends on factors such as platform requirements, performance, and project goals.
